# Semiconductor News Aggregator

A real-time news aggregation platform focused on semiconductor geopolitics and US-China tech relations.

🔗 **[Live Demo](https://news-aggregator-ru4n.onrender.com/)**

## 📋 Overview

This web application aggregates and displays the latest news articles about semiconductor technology, US-China relations, and chip manufacturing. Features a professional Bloomberg-style terminal interface with real-time data updates.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **APIs:** NewsAPI for news aggregation, SendGrid for email delivery
- **Frontend:** HTML/CSS (custom Bloomberg terminal-inspired design)
- **Deployment:** Render
- **Version Control:** Git, GitHub

## ✨ Features

- Real-time news fetching from multiple keyword searches
- Professional dark theme terminal interface
- Live status indicators and dashboard metrics
- Automated daily email digests (separate script)
- Responsive design for mobile and desktop
- Clean, organized article presentation with metadata

## 🚀 Live Demo

Visit the live application: https://news-aggregator-ru4n.onrender.com/

## 📧 Email Automation

Includes a separate script (`news_aggregator.py`) that can be scheduled via cron to send daily email digests of semiconductor news.
